# Octonaut verification map

Start with a newly created simulator and a Debug fixture launch from ../SKILL.md. Read the matching journey before acting. Use fresh snapshot refs for every screen, and retain action responses, before/after snapshots, screenshots, and side-effect checks under RUN/evidence. Report unmet preconditions as failures or skips; another entry point does not verify the missing one.

- [Settings](settings.md): navigation and stored sorting preference.
- [Feeds](feeds.md): feed selection and custom feed editor.
- [Comments](comments.md): post detail and collapse/expand.
- [Search](search.md): post/community/user search.
- [Media](media.md): gallery navigation and dismissal.

This is an initial map, not full coverage. Account switching, reporting, drafts, export, summaries, iCloud delivery, iPad layout, and the Mac shell need additional journeys. No credentials are seeded. Never log in or send Reddit actions to satisfy a fixture precondition.
