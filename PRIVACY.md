## 🔐 Octonaut Privacy Policy

Octonaut does not record or send any telemetry. This means:
- No demographic information is collected
- No usage information is collected
- No crash or debugging logs are collected
- I get no information from your device whatsoever.

If you are using this app via TestFlight, there is an error reporting function that is supplied by Apple as part of the TestFlight service, it is not a part of this app. When you submit information via this function the data you submit is collected by Apple and made accessible to me (the developer).
This app is not affiliated with Reddit, however the app contacts Reddit directly to load content; therefore, Reddit is able to see requests that you have made and what content you are consuming, and if you are logged in, be able to associate this activity with your account, therefore you are subject to [Reddit's Privacy Policy](https://www.redditinc.com/policies/privacy-policy) when you use this app. 
If you create a Multireddit/custom feed, these sync across your devices (where you use both the same iCloud and Reddit accounts). This is not a native Reddit feature; the sync is powered by Apple's iCloud service and your multireddit settings are being uploaded to Apple.
By default, post and comment summaries are generated on device (or disabled if your device doesn't support Apple Intelligence). If you choose an OpenAI-compatible summary provider, its API key is also stored in Keychain and the selected post or comment text is sent to that provider.

If you have any questions, please log an issue on Octonaut's [Github Issues page](https://github.com/ledwardchow/Octonaut/issues).
